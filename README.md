# Process Intelligence Platform

An enterprise-grade Process Mining and Business Intelligence Platform built with vanilla ES modules, CSS glassmorphic variables, IndexedDB persistence, and an client-side SQL engine.

## Features

- **Process Mining Engine**: Directly-Follows Graph (DFG) generation with variant aggregation, process map rendering, topological layering, and slider filtering.
- **Data Hub & SQL Transformation Engine**: Client-side SQL execution engine supporting `GROUP BY`, `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX` aggregations.
- **File Ingestion**: Imports CSV, TSV, XLSX (via SheetJS), and IEEE XES event log files.
- **Dashboard Studio**: Free-form grid canvas supporting widget repositioning, KPI cards, and data charts.
- **Glassmorphism & Multi-Theme System**: Supports Light, Dark, Carbon, Azure, Emerald, Purple, Orange, Blue, Graphite, High Contrast, and Midnight palettes.
- **No-Backend Storage**: Uses IndexedDB for state persistence beyond standard browser `localStorage` limits.
